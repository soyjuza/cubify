# Imagen en cubos

Página que convierte una imagen en cubos y los anima. Tiene 4 efectos: remolino, viento, explosión y derrumbe.

Se puede descargar el resultado como imagen PNG o como video.

## Cómo usarla

1. Subir una imagen o elegir uno de los ejemplos.
2. Elegir el efecto, el tamaño de los cubos, la duración y el color de fondo.
3. Darle a Reproducir o mover la barra de avance.
4. Descargar la imagen o el video.

Se ve mejor con imágenes sin fondo (PNG transparente).

## Cómo abrirla

Hay que abrirla con Live Server en Visual Studio Code. Con doble clic no funciona porque el navegador no deja leer los pixeles de las imágenes.

## Tecnologías

HTML, CSS y JavaScript con Canvas.
